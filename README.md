# Students Grades Analysis

A data analysis project built with Python, NumPy, and Matplotlib.

## Project Overview

This project analyzes the grades of five students across three subjects.
The goal is to practice NumPy for numerical data analysis and Matplotlib
for data visualization.

## What I Did

- Created and organized student grade data using NumPy arrays
- Analyzed the shape and structure of the dataset
- Calculated average grades for each student
- Calculated average grades for each subject
- Identified the highest and lowest student averages
- Identified the highest and lowest subject averages
- Calculated the overall average
- Created visualizations using Matplotlib
- Extracted key findings from the results

## Technologies Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

## Visualizations

The project includes bar charts showing:

- Average grade by subject
- Average grade for each student

## Key Findings

The final notebook contains the main findings and observations
based on the analysis.
